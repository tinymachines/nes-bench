# Photographs from the bench

`tools/bringup.py` asks for a photograph at each physical step and names
the file it wants. Put them here with exactly that name and push them;
re-running `tools/lab-notebook.py` embeds the ones that have arrived and
lists the ones that have not, so the notebook never carries a broken
image and never quietly forgets a missing one.

These are the record of a build that happened once. They are committed,
unlike the captures and the run directories.
